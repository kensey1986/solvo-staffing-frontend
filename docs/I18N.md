# Internationalization (i18n)

Multi-language support for the Solvo Platform Frontend application. Currently supports **English** and **Spanish** with runtime language switching.

## Overview

The application uses [`@ngx-translate/core`](https://github.com/ngx-translate/core) with [`@ngx-translate/http-loader`](https://github.com/ngx-translate/http-loader) for runtime-based translations. This approach allows switching languages instantly without reloading the application or requiring separate builds per language.

```
│  │       |'es'> │  └──────────────┘  └──────────────────┘   │

│         │          effect()                 │               │
│         └───────────────────────────────────┘               │
└──────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────────┐
│                   Translation Files                          │

└──────────────────────────────────────────────────────────────┘
                          │

┌──────────────────────────────────────────────────────────────┐

│  {{ 'DASHBOARD.TITLE' | translate }}                        │

└──────────────────────────────────────────────────────────────┘
```

## Supported Languages

| Code | Language | Default |
|------|----------|---------|
| `en` | English  | Yes     |
| `es` | Spanish  | No      |

The default language is **English**. The user's preference is persisted in `localStorage` under the key `solvo-language-preference`.

## Configuration

### `app.config.ts`

Translation is configured at the application root using `TranslateModule.forRoot()` and `provideTranslateHttpLoader()`:

```typescript
import { TranslateModule } from '@ngx-translate/core';
import { provideTranslateHttpLoader } from '@ngx-translate/http-loader';

export const appConfig: ApplicationConfig = {
  providers: [
    // ...
    importProvidersFrom(
      TranslateModule.forRoot({
        defaultLanguage: 'en',
      })
    ),
    provideTranslateHttpLoader({
      prefix: './assets/i18n/',
      suffix: '.json',
    }),
  ],
};
```

> **Note**: `@ngx-translate/http-loader` v17+ uses `provideTranslateHttpLoader()` instead of the constructor-based `TranslateHttpLoader` class.

## LanguageService

Located at `src/app/core/services/language.service.ts`.

Follows the same pattern as `ThemeService` using Angular Signals:

```typescript
export type Language = 'en' | 'es';

@Injectable({ providedIn: 'root' })
export class LanguageService {
  readonly language = signal<Language>('en');

  setLanguage(lang: Language): void {
    this.language.set(lang);
  }
}
```

### Behavior

1. **Initialization**: Reads `localStorage` for a previously saved preference. If none exists, defaults to `'en'`.
2. **Reactive effect**: When `language()` changes, the effect:
   - Calls `TranslateService.use(lang)` to load and apply translations
   - Updates `document.documentElement.lang` for accessibility
   - Persists the choice to `localStorage`

## LanguageSwitcherComponent

Located at `src/app/shared/components/language-switcher/language-switcher.component.ts`.

Standalone inline-template component that displays a `language` Material icon button with a dropdown menu. The menu only shows the **alternate** language (not the current one):

- If the current language is English, the menu shows "Spanish"
- If the current language is Spanish, the menu shows "English" (Inglés)

### Usage

```html
<app-language-switcher />
```

The component is placed in the toolbar of both layout components:
- **MainLayoutComponent** - Between theme toggle and notifications
- **AuthLayoutComponent** - Next to theme toggle

## Usage in Components

### Template (translate pipe)

```html
<!-- Simple key -->
<h1>{{ 'DASHBOARD.TITLE' | translate }}</h1>

<!-- With attribute binding -->
<button [matTooltip]="'THEME.SWITCH_TO_DARK' | translate">

<!-- With parameters -->
<span>{{ 'COMPANIES.SHOWING' | translate:{ start: 1, end: 10, total: 50 } }}</span>
```

### TypeScript (programmatic)

```typescript
import { TranslateService } from '@ngx-translate/core';

export class MyComponent {
  private readonly translate = inject(TranslateService);

  showMessage(): void {
    const message = this.translate.instant('CREATE_COMPANY.SUCCESS');
    this.snackBar.open(message, 'OK', { duration: 3000 });
  }
}
```

### Component Setup

Every component using translations must import `TranslateModule`:

```typescript
@Component({
  standalone: true,
  imports: [TranslateModule],
  // ...
})
```

## Adding a New Translation Key

1. Add the key to **both** `public/assets/i18n/en.json` and `public/assets/i18n/es.json`
2. Use the appropriate namespace or create a new one if needed
3. Use `{{ 'NAMESPACE.KEY' | translate }}` in the template or `this.translate.instant('NAMESPACE.KEY')` in TypeScript

### Example

```json
// en.json
{
  "MY_FEATURE": {
    "TITLE": "My Feature",
    "DESCRIPTION": "This is my feature"
  }
}

// es.json
{
  "MY_FEATURE": {
    "TITLE": "Mi Funcionalidad",
    "DESCRIPTION": "Esta es mi funcionalidad"
  }
}
```

## Adding a New Language

1. Create a new translation file: `public/assets/i18n/{code}.json`
2. Copy the structure from `en.json` and translate all values
3. Update the `Language` type in `language.service.ts`:
   ```typescript
   export type Language = 'en' | 'es' | 'pt';
   ```
4. Add validation in `initializeLanguage()` for the new code
5. Add a new menu item in `LanguageSwitcherComponent`
6. Add translation keys for the new language name in `LANGUAGE` namespace
